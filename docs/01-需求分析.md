# 01-需求分析

## 项目背景

本项目是数据库课程大作业，选题为基于 SpringBoot3 + Vue3 的 Web 小型商城平台。系统围绕“商品浏览、购物车、地址、下单、支付、发货、统计”构建完整业务闭环，便于在课程报告中展示数据库设计、事务处理、权限控制和统计查询。

## 系统目标

- 实现普通用户从注册登录到提交订单的购物流程。
- 实现管理员对商品、分类、订单、用户和统计数据的管理。
- 通过订单创建流程体现数据库事务一致性。
- 通过订单明细快照和地址快照体现合理的数据冗余设计。
- 提供 SQL 脚本、接口测试文件和报告素材，支撑课堂展示。

## 用户角色

| 角色 | 权限 |
|---|---|
| 游客 | 浏览商品、搜索商品、查看详情、注册、登录 |
| 普通用户 | 管理地址、购物车、订单、模拟支付 |
| 管理员 | 管理分类、商品、用户、订单、查看统计 |

## 功能需求

- 用户模块：注册、登录、JWT 鉴权、查看和修改个人信息、修改密码、管理员启停用户。
- 分类模块：分类查询、管理员新增、修改、删除或停用。
- 商品模块：分页查询、分类筛选、关键词搜索、详情、管理员增删改、上下架、改库存。
- 购物车模块：加入购物车、修改数量、删除、清空、同用户同商品唯一约束。
- 地址模块：新增、修改、删除、设置默认地址，同一用户最多一个默认地址。
- 订单模块：从购物车创建订单、支付、取消、用户订单查询、管理员查询与发货。
- 统计模块：订单数、销售额、待发货订单、商品数、低库存列表、销量排行 Top 5。

## 非功能需求

- 密码使用 BCrypt 加密，不能明文存储。
- 后端必须校验 Token 和角色权限。
- 参数校验和异常响应统一。
- 数据库使用主键、外键、唯一约束、检查约束和索引。
- 页面布局清晰，具备加载、空状态和操作提示。

## 核心业务流程

用户注册或登录后浏览商品，选择商品加入购物车，维护收货地址，在结算页选择购物车项和地址提交订单。后端在事务中创建订单主表、订单明细表、扣减库存、增加销量并删除购物车项。用户完成模拟支付后，管理员在后台筛选待发货订单并发货，用户可查看订单状态变化。
