# 02-系统设计

## 架构设计

系统采用前后端分离架构：

- 前端：Vue3 + Vite + Vue Router + Pinia + Axios + Element Plus。
- 后端：SpringBoot3 + Spring Web + Validation + MyBatis-Plus + JWT 拦截器。
- 数据库：MySQL 8，提供 `schema.sql` 和 `data.sql`。

前端通过 Axios 访问 `/api/**` 接口，开发环境由 Vite 将 `/api` 代理到后端 `http://localhost:8080`。

## 模块划分

| 模块 | 说明 |
|---|---|
| 用户模块 | 注册、登录、Token、个人资料、用户启停 |
| 商品分类模块 | 分类展示和后台维护 |
| 商品模块 | 商品查询和后台维护 |
| 购物车模块 | 用户购物车增删改查 |
| 地址模块 | 收货地址与默认地址 |
| 订单模块 | 订单创建、支付、取消、发货 |
| 统计模块 | 后台聚合查询 |

## 后端分层结构

- Controller：接收参数、调用 Service、返回统一 `Result`。
- Service：封装业务规则和事务。
- Mapper：MyBatis-Plus 数据访问。
- DTO：请求对象。
- VO：响应视图对象。
- Security：JWT 拦截器、登录上下文、管理员注解。
- Exception：业务异常和全局异常处理。

## 前端页面结构

用户端：

- `/` 商品首页。
- `/login`、`/register` 登录注册。
- `/products/:id` 商品详情。
- `/cart` 购物车。
- `/checkout` 结算。
- `/address` 地址管理。
- `/orders`、`/orders/:id` 订单列表和详情。

管理员端：

- `/admin` 统计概览。
- `/admin/products` 商品管理。
- `/admin/categories` 分类管理。
- `/admin/orders` 订单管理。
- `/admin/users` 用户管理。

## 主要流程描述

订单创建流程：

1. 用户选择购物车商品并提交收货地址。
2. 后端校验地址归属当前用户。
3. 后端查询购物车项和商品记录。
4. 校验商品上架状态和库存。
5. 创建订单主表并保存地址快照。
6. 创建订单明细并保存商品名称、价格、图片快照。
7. 执行安全库存扣减 SQL。
8. 删除已结算购物车项。
9. 事务提交，返回订单号和金额。
