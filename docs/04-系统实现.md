# 04-系统实现

## 开发环境

- JDK：17+
- Maven：3.8+
- MySQL：8.x
- Node.js：18+
- npm：9+

## 后端实现说明

后端入口为 `MallApplication`。项目使用 MyBatis-Plus 简化基础 CRUD，通过自定义 Mapper SQL 实现安全库存扣减和统计聚合。统一返回结构为 `Result<T>`，统一分页结构为 `PageResult<T>`。

异常处理由 `GlobalExceptionHandler` 统一处理业务异常、参数校验异常和系统异常。密码使用 `BCryptPasswordEncoder` 加密。JWT 工具类负责生成和解析 Token。

## 前端实现说明

前端使用 Vue3 单页应用。`router/index.js` 配置用户端与管理员端路由，`store/auth.js` 保存 Token 和用户信息，`utils/request.js` 封装 Axios 并自动携带 Token。

Element Plus 用于表格、表单、弹窗、分页、消息提示和布局。

## 核心功能实现

- 商品列表支持分页、分类筛选和关键词搜索。
- 购物车支持增删改查和库存上限校验。
- 地址支持默认地址互斥。
- 订单创建返回订单 ID、订单号和总金额。
- 订单支持付款备注、管理员确认收款、发货物流单号、用户确认收货和待支付取消。
- 管理员后台支持商品、分类、订单、用户和统计。

## 订单事务处理说明

`OrderServiceImpl#createOrder` 是核心事务方法。该方法先校验用户地址和购物车归属，再查询商品并检查库存，随后创建订单主表和订单明细，执行安全库存扣减，最后删除购物车项。任一步抛出异常都会触发事务回滚。

订单状态流转由后端统一校验：待支付订单可提交付款备注或取消，管理员确认收款后进入待发货，发货后用户可确认收货。取消待支付订单会按照订单明细恢复商品库存并回退销量，非法状态流转返回业务错误。

## 权限控制说明

后端通过 `JwtAuthInterceptor` 拦截 `/api/**` 中需要登录的接口。公开接口包括注册、登录、分类查询、商品查询和商品详情。管理员接口路径 `/api/admin/**` 需要用户角色 `role = 1`。前端路由守卫只负责用户体验，真正的权限校验在后端完成。
