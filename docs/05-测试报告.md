# 05-测试报告

## 测试环境

推荐演示环境：

| 项目 | 说明 |
|---|---|
| 前端入口 | `http://localhost:8088` |
| 后端健康检查 | `http://localhost:8088/api/health` |
| 后端直连 | `http://localhost:8080/api/health` |
| 数据库 | MySQL 8，端口 `3307` |
| 启动方式 | `docker compose up -d --build` |

如果本机没有 Docker，也可以使用本地 MySQL、Maven 和 npm 分别启动。

## 功能测试用例

| 编号 | 测试模块 | 测试内容 | 预期结果 |
|---|---|---|---|
| T000 | 服务 | 访问 `/api/health` | 返回 `status=UP` |
| T001 | 用户 | 注册新用户 | 注册成功，密码加密入库 |
| T002 | 用户 | 重复用户名注册 | 注册失败，返回用户名已存在 |

| T004 | 商品 | 查询商品列表 | 返回上架商品分页数据 |
| T005 | 商品 | 按分类筛选 | 返回对应分类商品 |
| T006 | 购物车 | 加入购物车 | 添加成功，同商品合并数量 |
| T007 | 购物车 | 超库存添加 | 添加失败 |
| T008 | 订单 | 创建订单 | 订单、明细、库存、购物车正确变化 |

## 关键验证点

- 查看 `order_info` 是否新增订单主表记录。
- 查看 `order_item` 是否保存商品名称、价格和图片快照。
- 查看 `product.stock` 是否扣减，`product.sales` 是否增加。
- 查看 `cart_item` 中已结算商品是否删除。
- 模拟库存不足时，订单主表和明细不应产生脏数据。
