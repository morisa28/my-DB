| 编号 | 测试模块 | 测试内容 | 预期结果 |
|---|---|---|---|
| T001 | 用户 | 注册新用户 | 注册成功，密码加密入库 |
| T002 | 用户 | 重复用户名注册 | 注册失败，返回用户名已存在 |

| T004 | 商品 | 查询商品列表 | 返回上架商品分页数据 |

| T008 | 订单 | 创建订单 | 订单、明细、库存、购物车正确变化 |
| T009 | 订单 | 库存不足下单 | 下单失败并回滚 |
| T010 | 权限 | 普通用户访问后台 | 返回 403 |
| T011 | 后台 | 管理员发货 | 订单状态变为已发货 |
| T012 | 统计 | 查看销售统计 | 返回聚合统计数据 |

## 关键验证点

- 查看 `order_info` 是否新增订单主表记录。
- 查看 `order_item` 是否保存商品名称、价格和图片快照。
- 查看 `product.stock` 是否扣减，`product.sales` 是否增加。
- 查看 `cart_item` 中已结算商品是否删除。
- 模拟库存不足时，订单主表和明细不应产生脏数据。
