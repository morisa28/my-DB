# 06-实验总结

## 项目完成情况

本项目完成了一个可演示的小型商城平台，覆盖普通用户购物流程和管理员后台管理流程。后端实现了 JWT 鉴权、统一异常处理、统一响应、MyBatis-Plus 数据访问和订单事务。前端实现了商品浏览、购物车、结算、地址、订单和后台管理页面。

## 数据库设计收获

本项目通过主键、外键、唯一约束、检查约束和索引体现了关系数据库的完整性设计。订单明细保存商品快照、订单主表保存地址快照，体现了历史数据稳定性的设计思想。

## 遇到的问题

- 订单创建涉及多个表，必须避免库存扣减成功但订单失败的情况。
- 默认地址需要保证同一用户最多一个。
- 普通用户不能访问管理员接口，不能只依赖前端隐藏菜单。

## 解决方案

- 使用 `@Transactional` 包裹订单创建流程。
- 使用安全库存扣减 SQL 防止库存变为负数。
- 设置默认地址时先清除该用户其他默认地址。
- 使用 JWT 拦截器和管理员角色校验保护后端接口。

## 不足与改进方向

- 可继续增加商品评价、订单完成、图片上传等功能。
- 可增加自动化单元测试和集成测试。
- 可引入 Docker Compose 简化 MySQL 环境搭建。
- 可增加更丰富的报表图表展示。
