# 阶段四交付文档：商品图片上传

## 阶段目标

将商品图片从外部示例 URL 扩展为可由管理员上传、可持久化保存、可由前端直接访问的本地文件能力。

## 完成内容

- 新增 `POST /api/admin/upload/product-image` 管理员上传接口。
- 新增上传配置：
  - `UPLOAD_DIR`
  - `UPLOAD_BASE_URL`
  - `UPLOAD_MAX_FILE_SIZE`
  - `UPLOAD_MAX_REQUEST_SIZE`
  - `UPLOAD_MAX_SIZE_BYTES`
- 后端校验：
  - 仅允许 `jpg`、`jpeg`、`png`、`webp`。
  - 最大 2MB。
  - 同时校验扩展名、Content-Type 和文件头签名。
  - 上传文件保存到 `product/yyyyMM/` 子目录。
- Spring Boot 增加 `/uploads/**` 静态资源映射。
- Docker Compose 增加 `mall-upload-data` 持久化卷，后端默认挂载 `/app/uploads`。
- Nginx 增加 `/uploads/` 代理到后端，使前端入口 `http://localhost:8088/uploads/...` 可直接访问图片。
- 后台商品管理支持上传、预览和保存图片 URL。
- 更新 `README.md`、`docs/deploy-demo.md`、`docs/05-测试报告.md`、`mall-backend/api-test.http`。

## 剩余边界

- 当前为服务器本地持久化目录，不是对象存储。
- `docker compose down -v` 会删除上传图片卷，生产环境不要用该命令重置。
- 真实商品图片素材仍需用户自行提供。
