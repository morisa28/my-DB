# 阶段五交付文档：账户、安全和配置加固

## 阶段目标

补齐小规模实用项目上线前的基础安全防线，确保关键权限由后端兜底，并让生产环境配置不再依赖代码中的默认值。

## 完成内容

- 错误响应改为真实 HTTP 状态码：
  - 未登录或无效 Token：HTTP 401。
  - 无管理员权限或禁用用户 Token：HTTP 403。
  - 参数和业务校验错误：HTTP 400。
  - 未捕获异常：HTTP 500。
- 登录失败统一返回“用户名或密码错误”，避免泄露账号是否存在或是否禁用。
- 生产环境 JWT 密钥校验：
  - `JWT_SECRET` 少于 32 字节时启动失败。
  - `SPRING_PROFILES_ACTIVE=prod` 且使用演示默认密钥时启动失败。
- CORS 允许来源改为环境变量 `CORS_ALLOWED_ORIGINS`。
- 已有后端拦截器继续保证：
  - 禁用用户已有 Token 请求返回 403。
  - 普通用户不能访问 `/api/admin/**`。
  - 管理员不能禁用自己。
- 更新 `.env.example`、`README.md`、`docs/deploy-demo.md`、`docs/05-测试报告.md` 和后续开发 Prompt。

## 剩余边界

- 当前未实现登录失败次数限制、验证码、短信或邮箱验证。
- 当前未做 Token 黑名单；禁用用户通过数据库状态即时拦截。
- 生产环境仍需要用户自行提供强随机 `JWT_SECRET`、HTTPS、域名和服务器安全组配置。
