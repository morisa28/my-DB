# 阶段八交付文档：前端实用体验

## 阶段目标

补齐真实使用中容易影响操作连续性的前端体验，包括全局错误处理、线下付款说明、后台操作确认、加载状态和移动端基础适配。

## 完成内容

- 全局请求错误处理：
  - HTTP 401 自动清理登录态并跳转登录页。
  - HTTP 403 展示无权限提示。
  - HTTP 500 展示通用系统错误提示，避免直接暴露服务端异常。
- 用户端：
  - 商品详情已展示库存和销量。
  - 结算页新增线下付款说明。
  - 订单列表和详情已支持取消、付款备注和确认收货。
- 管理端：
  - 商品保存和库存保存增加 loading 状态。
  - 商品上架/下架增加确认弹窗。
  - 用户启用/禁用增加确认弹窗。
  - 图片上传已具备预览。
- 移动端：
  - 弹窗、抽屉、表格文本增加基础响应式约束。
  - 结算页提交区域在窄屏下改为纵向布局。
