# 阶段十：服务器部署前交付包

## 阶段目标

将项目交付状态从“本地 Docker 可验收”收口为“用户可接手准备云服务器部署”。本阶段不新增业务功能，重点补齐服务器上线前检查、运维手册、用户责任边界和不可自动解决事项。

## 完成内容

- 新增 `docs/deploy-server-precheck.md`，覆盖服务器最低配置、Docker / Compose 要求、端口清单、`.env` 必填项、上传目录挂载、数据库初始化、备份建议、验收步骤、用户必须完成事项和上线前风险。
- 新增 `docs/ops-runbook.md`，覆盖启动停止、健康检查、日志查看、数据库备份、上传文件备份、数据恢复、更新发布、回滚方式、常见故障排查和日常运营建议。
- 更新 `README.md`，在部署文档入口中加入服务器部署前检查和运维手册。
- 更新 `docs/09-Codex后续开发Prompt.md`，把当前进度同步到第一阶段至第十阶段已完成，并明确后续不应再把服务器、域名、HTTPS、真实支付等用户侧事项伪装为代码侧已完成。

## 未完成 / 风险

- 用户仍需自行准备云服务器、域名、HTTPS 证书、安全组和正式 `.env`。
- 生产环境是否使用云数据库、对象存储、真实支付、短信、邮件或物流 API，仍需用户后续决策并提供账号、密钥和接口文档。
- 当前项目定位为小规模自营商城，不覆盖高并发、多商户、复杂促销和完整售后系统。

## 建议下一步

- 用户准备云服务器后，按 `docs/deploy-server-precheck.md` 创建正式 `.env` 并完成首次部署。
- 部署后按 `docs/ops-runbook.md` 建立备份、发布和回滚习惯。
- 如需继续升级，优先考虑修改默认管理员密码流程、真实支付接入、对象存储、审计日志和更完整的自动化测试。
