# 阶段十四：测试审计与前端分包优化

## 阶段目标

补齐阶段十三遗留的自动化测试、订单操作审计和前端构建体积问题，让项目从“可演示”继续向“小规模实用”推进。

## 完成内容

### 1. 后端集成测试

新增 Spring Boot 集成测试基类和两组测试用例：

- `MallIntegrationTestBase`
- `OrderWorkflowIntegrationTest`
- `SecurityAndValidationIntegrationTest`

测试通过已启动的 Docker Compose MySQL 执行，避免把宿主 Docker socket 挂进 Maven 容器。

覆盖范围：

- 完整订单状态流转：创建订单、提交付款备注、管理员确认收款、发货、用户确认收货。
- 订单取消后库存和销量恢复。
- 重复确认收货、重复取消、重复结算同一购物车项等幂等边界。
- 未登录访问购物车返回 401。
- 普通用户访问后台返回 403。
- 管理员列表参数非法返回 400。
- 普通用户上传商品图片返回 403。
- 管理员上传伪 PNG 返回 400。

### 2. 订单操作审计日志

新增 `order_operation_log` 表，记录订单关键操作：

- `CREATE_ORDER`
- `SUBMIT_PAYMENT_NOTE`
- `CONFIRM_PAYMENT`
- `SHIP_ORDER`
- `CANCEL_ORDER`
- `CONFIRM_RECEIPT`

新增接口：

```text
GET /api/admin/orders/{id}/logs
```

管理员订单详情抽屉已展示“操作记录”，包括操作类型、操作者、操作者角色、状态流转和备注。

### 3. 数据库升级脚本

已同步更新全量建表脚本：

```text
mall-backend/src/main/resources/sql/schema.sql
```

已有数据库需要先备份，再执行增量脚本：

```bash
mysql -u root -p mall_db < mall-backend/src/main/resources/sql/migration/V20260520__order_operation_log.sql
```

### 4. 前端分包和 Element Plus 按需注册

优化项：

- 移除 `app.use(ElementPlus)` 全量注册。
- 只注册当前项目实际使用的 Element Plus 组件。
- 只注册当前菜单实际使用的图标组件。
- 将 `ElMessage`、`ElMessageBox` 改为直接组件路径导入。
- 在 Vite 中配置 `manualChunks`，拆分 Vue、Axios、Element Plus 组件和图标 chunk。

构建结果中已不再出现 Vite `Some chunks are larger than 500 kB` 警告。

### 5. 业务验收脚本增强

`scripts/practical-flow-check.mjs` 已新增订单审计日志断言：

- 完成订单必须包含创建、付款备注、确认收款、发货、确认收货日志。
- 取消订单必须包含取消日志。
- 输出摘要新增 `operationLogCount`。

## 未完成 / 风险

- 当前仍未引入 Flyway/Liquibase，数据库升级依赖手动执行 `migration/` 脚本；小规模部署前必须严格备份并记录已执行脚本。
- 订单审计已覆盖核心流转，但还未覆盖商品、用户、分类等后台管理操作审计。
- 前端 CSS 仍包含 Element Plus 核心样式包，JS 体积已拆分，但后续仍可继续做 CSS 按需引入。
- 浏览器检查覆盖 Chromium，尚未覆盖 Firefox、Safari 和真实移动设备。
- 当前支付仍为线下付款备注流程，真正投入使用前如需线上支付，还需重新设计支付状态机、回调验签和对账流程。
