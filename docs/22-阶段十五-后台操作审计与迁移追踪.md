# 阶段十五：后台操作审计与迁移追踪

## 阶段目标

继续补齐小规模实用项目的审计和运维缺口，让后台管理动作可追踪、数据库手动迁移可记录、前端冒烟检查可重复执行。

## 完成内容

### 1. 后台管理操作审计

新增 `admin_operation_log` 表，用于记录后台管理动作：

- 操作者 ID 和用户名。
- 模块：`PRODUCT`、`CATEGORY`、`USER`。
- 动作：创建商品、更新商品、下架商品、更新库存、创建分类、更新分类、停用或删除分类、更新用户状态。
- 操作对象 ID、对象名称、备注和操作时间。

新增接口：

```text
GET /api/admin/operation-logs
```

支持按 `module` 和 `action` 筛选，返回分页数据。

### 2. 后台操作日志页面

新增管理员页面：

```text
/admin/operation-logs
```

页面包含模块筛选、动作筛选、日志表格和分页。后台侧边栏已增加“操作日志”入口。

### 3. 数据库迁移执行记录

新增 `schema_migration_history` 表，用于记录手动执行过的增量脚本。

新增脚本：

```text
mall-backend/src/main/resources/sql/migration/V20260520_00__schema_migration_history.sql
mall-backend/src/main/resources/sql/migration/V20260520_02__admin_operation_log.sql
```

已更新 `V20260520__order_operation_log.sql` 和 `V20260520_02__admin_operation_log.sql`，脚本执行后会写入 `schema_migration_history`。

### 4. 前端冒烟检查脚本固化

新增：

```text
scripts/frontend-smoke-check.mjs
```

覆盖：

- 桌面首页非空白页检查。
- 管理员登录。
- 管理员订单详情抽屉中的订单审计记录。
- 管理员操作日志页面。
- 移动端首页非空白页检查。
- 控制台 error 检查。

截图默认输出到：

```text
/tmp/mall-frontend-smoke/
```

## 未完成 / 风险

- 仍未引入 Flyway/Liquibase；当前是轻量手动迁移记录方案，服务器部署时仍必须按文档顺序执行 migration 并备份。
- 后台操作审计已覆盖商品、分类和用户状态；上传图片、统计查询等只读或文件类动作暂未记录。
- 前端冒烟脚本依赖本机可用的 Playwright 模块；仓库暂未把 Playwright 加入前端 devDependencies，避免增加项目依赖体积。
- 审计日志目前没有归档和保留周期策略；小规模使用可先保留，后续数据增长后需要定期归档。
